# Ford Player — Android · довідка

BLE-only пульт для аудіо-комплексу: плеєр, плейлист, OTA, логи й моніторинг.
Працює без Wi-Fi — усе через Bluetooth LE (JSON-RPC).

## Три репозиторії (пов'язані між собою)

| Компонент | Репозиторій | Роль |
|---|---|---|
| **Master** | https://github.com/freebsdmax/Ford-DensO-mp3-master | ESP32-S3: MP3, BLE-сервер, Web UI, OTA |
| **Slave** | https://github.com/freebsdmax/Ford-DensO-bluetooth-slave | ESP32: A2DP/AVRCP, I2S, UART |
| **App** (цей) | https://github.com/freebsdmax/Esp32_Android_app | Android-пульт до Master |

Повна довідка по системі: **`HELP.md` у репозиторії Master**
(https://github.com/freebsdmax/Ford-DensO-mp3-master/blob/debug/HELP.md).

## Екрани

| Вкладка | Що там |
|---|---|
| **Плеєр** | назва/виконавець, ⏮ ▶/⏸ ⏭, прогрес із перемоткою, чіпи **режим** (USB ↔ external) і **CAN** — тап перемикає |
| **Плейлист** | треки з USB, вибір треку |
| **OTA** | оновлення з GitHub (застосунок / Master / Slave) + версії Master і Slave |
| **Логи** | 5 груп (плеєр, зв'язок, OTA, авто, система), автозавантаження при відкритті |

Налаштування (шестерня): підключення (Від'єднати / **Оновити** / Сканувати),
зовнішній вигляд, сон (секунди 10–28800, режим), **прошивка вручну** (.bin з телефона).

## Оновлення

```
1. качає .bin з GitHub Release  →  трей: прогрес
2. заливає у /storage/master.bin (або slave.bin) на платі
3. просить плату прошитись з файлу
4. плата прошиває і видаляє файл лише після успіху
```

- працює у фоні: foreground service + сповіщення у шторці (%, швидкість, ETA);
- після прошивки Master плата перезавантажується — застосунок сам перепідключається;
- якщо прошивка впала, файл лишається на платі: повторна спроба без інтернету.

APK оновлюється так само з картки «Застосунок» (завантаження → системний інсталятор).

## Bluetooth: типові проблеми

| Симптом | Що робить застосунок |
|---|---|
| «Підключено», але пусто | watchdog: 12 с без сервісу або 6 невдалих запитів → переконнект |
| Зв'язок флапає | повідомлення показуються лише якщо стан протримався 3 с |
| Нічого не допомагає | Налаштування → Підключення → **Оновити** (без очистки даних) |
| Дозволи злетіли | видати `BLUETOOTH_SCAN`, `BLUETOOTH_CONNECT`, `POST_NOTIFICATIONS` |

## GitHub і ліміт запитів

Перевірка оновлень іде через GitHub API **без авторизації — 60 запитів/год на IP**.
Тому: кеш 15 хв, `ETag`/`If-None-Match` (відповідь 304 не рахується), а при
вичерпанні ліміту показуються збережені дані + точний час скидання.

## Збірка

```powershell
cd D:\emulators\Ford-DensO-mp3-master\AndroidPlayer
.\gradlew.bat assembleDebug          # debug APK
.\gradlew.bat assembleRelease        # release (потрібен keystore)
```

Підписаний реліз збирає CI на тег `v*` (keystore у secrets, `versionName` з тега).
