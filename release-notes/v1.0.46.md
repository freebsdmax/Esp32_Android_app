- **Виправлено червоне повідомлення «Не вдалося увімкнути BLE-сповіщення»** на екрані сканування: одразу після підключення Android інколи відмовляє у записі CCCD, бо стек GATT ще зайнятий запитом MTU або пошуком сервісів. Тепер дескриптор повертається в чергу і запис повторюється (до 20 спроб із наростаючою паузою 100–1100 мс), а повідомлення з'являється лише якщо всі спроби вичерпано.
- Порядок вмикання сповіщень не змінено: Status → Playlist → Logs, кожен наступний запис стартує після підтвердження попереднього (як у робочій v1.0.45).
- Помилка зникає сама, щойно сповіщення вмикаються; текст повідомлення українською.
- На Android 13+ використовується новий API `writeDescriptor(descriptor, value)`, на старіших — сумісний виклик.
